# B2 - Build performance grid and editing interface

## Goal

Deliver the V1 offline virtual pad for a drummer on Mac, with Windows development,
strict layers, const-object enums and mutation-tested behavior. This slice is B2.

## Read first

Read AGENTS.md, docs/spec.md, docs/architecture.md and docs/delivery-plan.md.
Read .pstack/codex-t3.md before upstream pstack instructions, then the installed
.agents/skills/pstack/skills/poteto-mode/SKILL.md and
.agents/skills/pstack/skills/principle-test-behavior-not-implementation/SKILL.md.
The dispatch tool appends absolute paths and the exact base SHA.

## Scope

Use the installed .agents/skills/impeccable/SKILL.md for design/critique together
with shadcn/ui. Read docs/ui.md. This is an Operate surface: clarity and restraint
serve the drummer; marketing-page decoration does not.
The operator explicitly dislikes redundant subtitles. Keep headings and labels
only when they orient an action; avoid decorative eyebrows and repeated helper
copy. Prioritize pad names, active state, remaining time and the STOP action.

Use the shadcn/ui component decision in docs/ui.md. Bootstrap the approved local
primitives rather than recreating buttons, dialogs or form controls. Dependency,
Tailwind and Vite changes remain coordinated with the integrator.

Implement grid, persistent STOP/progress, busy states and edit mode using accepted controller/desktop contracts. Support import, label/color changes, drag order and delete confirmation; report truthful save errors.

Owned paths are authoritative in .pstack/work.json for B2. Shared contracts,
bootstrap/preload, dependencies, CI and checks belong to the integrator unless this
task explicitly owns them. Propose required shared edits with a concrete patch;
continue independent work. Do not weaken checks or expand product scope.

## Verification

Run npm ci if dependencies are absent. Run npm run verify and, for Electron wiring,
npm run package. Extend the existing test discovery/mutation scope for new behavior
through the integrator. Report actual commands and exit codes, never planned ones.

Harness shows real user journeys, persistent order, 31+ pads, no restart/switch during playback and STOP accessible while scrolling. Editing never interrupts playback. Keep accessibility checks and mutation on any new nonvisual logic.

## Live and performance gate

UI does not create Audio, access filesystem or duplicate playback state. Coordinate dependencies/config changes with integrator.

Measure only with a stated baseline, metric, method and hardware. Pure contract
work may explain why physical performance is not applicable; never substitute a
made-up number. Missing runtime evidence is a gap, not a pass.

## Handoff

Return PASS, ISSUES or BLOCKED. Include base/head SHA, changed paths, observed
behavior, commands/exit codes, mutation counts and artifacts, and remaining gaps.
Commit coherent work in the provided checkout. Do not merge or change shared main.
The coordinator owns integration, remote publication and PR monitoring. Do not
spawn nested agents. No review claim without reading the actual diff.
