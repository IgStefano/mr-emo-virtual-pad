# Performance surface

Operate mode. Dark neutral surfaces support dim rehearsal/show environments.
System sans text follows desktop expectations. Pad names dominate a responsive
grid; colored outlines group tracks without making color the only state signal.
Active pads invert to their selected color and carry a text status.

Tokens: background #111416, raised surface #252b30, text #f3f3ef,
secondary #bbc2c8, STOP #e25856; red #ff797e, blue #71b4ff,
green #68d59e, amber #eec76a, slate #a7b2c3.
Spacing: 8/12/18/26/32px. Controls minimum 44px; pads 144px tall.
Fixed bottom transport reserves 130px in the main layout. Scroll belongs to the
grid. Headings name the repertoire only. Edit controls appear exclusively in
stopped edit mode. Deletion uses a focus-managed Radix dialog.
