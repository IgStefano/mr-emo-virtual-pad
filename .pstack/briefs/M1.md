# M1: restricted local protocol adapters

Deliver offline media for the drummer's pad, without arbitrary path access or
leaked streams. Implement only the M1 interfaces in docs/integration-seams.md.
Read AGENTS.md, docs/spec.md, docs/architecture.md, .pstack/codex-t3.md and the
installed pstack poteto-mode and TypeScript skills before editing.

Implement ManagedMediaProtocol and ApplicationProtocol in the two owned storage
files. Use real temporary files and web Request/Response objects. Test exact bytes
for full GET, HEAD, normal/open/suffix ranges, invalid or unsatisfiable ranges,
unauthorized and expired leases, malformed IDs/URLs, traversal and symlink escapes,
missing files, abort/revoke/dispose cleanup and repeated cleanup. Handle actual
stream failures without silently authorizing another resource. Keep memory bounded
for long tracks; do not read entire audio files into memory to serve a range.

Do not import Electron, register schemes, edit bootstrap, contracts, dependencies
or shared tooling. Existing metadata support and mutation discovery are ready.
If a shared change is necessary, return a concrete patch in your evidence and
complete the independent adapter work. Do not create a generic path-based server.

Run npm ci, focused tests, npm run verify and the normal commit hook. Mutation must
include the actual new adapter behavior at the unchanged 100% gate. Persist through
failures with meaningful behavioral checks or simpler code. Do not inspect private
fields, suppress mutants or weaken checks. This module's evidence is real local
streaming, not Electron playback or physical audio. No hardware blocker prevents
this slice. Commit the complete owned slice and return PASS/ISSUES/BLOCKED with
base/head, commands/exit codes, artifacts and remaining integration gaps.
Do not spawn agents, publish, merge main or edit the coordinator's manifest.
