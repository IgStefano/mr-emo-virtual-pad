# Mr. Emo Virtual Pad

<!-- impeccable:product-schema 1 -->

## Platform

web

Electron desktop application for Mac, developed and checked on Windows too.

## Users

A drummer operating tracks by mouse or trackpad during rehearsal and shows.

## Capabilities and Constraints

Offline persistent repertoire, typically 20–30 tracks without a hard limit.
One active track, always starting at zero. STOP before switching. No pause,
loop, autoplay or mixer. Edit only while stopped; batch import copies originals.
Rename, color, reorder and deliberate deletion save through the desktop service.

## Evidence on Hand

Product truth: docs/spec.md. Target Mac/interface and physical latency remain
release verification requirements; no host measurement substitutes for them.
